# Customer Churn Prediction Using Machine Learning

## Project Overview
This project predicts whether a telecom customer is likely to leave a service provider using machine learning. It analyzes customer information to identify churn patterns and support customer retention strategies.

## Dataset
The dataset contains 1,000 customer records and 10 columns, including age, gender, tenure, monthly charges, contract type, internet service, technical support, total charges, and churn.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and inspection
2. Data cleaning and handling missing values
3. Exploratory Data Analysis (EDA)
4. Data preprocessing and feature selection
5. Train-test splitting and feature scaling
6. Model training and hyperparameter tuning
7. Model accuracy comparison and evaluation

## Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest

## Objective
To predict customer churn and help telecom companies identify customers who may leave their services.

## Outcome
The project compares multiple classification algorithms to identify a suitable churn prediction model. Model selection should consider precision, recall, F1-score, and confusion matrix alongside accuracy.
